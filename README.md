# Send Files

WindowsのAP（モバイルホットスポット）機能を利用して、Wi-Fiが無い場所でもiPadなどのデバイスと双方向でファイルを送受信できるシンプルなWebサーバーアプリです。

## 特徴
- **管理者権限不要**: 実行ファイル（.exe）を起動するだけで動作します。
- **Python不要**: Go言語で作成されているため、単一の実行ファイルで完結します。
- **双方向転送**: PCからiPadへ、iPadからPCへ、どちらも可能です。
- **複数ファイル対応**: 一度に複数のファイルを選択してアップロードできます。
- **セキュリティ**: Basic認証（ユーザー名: `admin`, パスワード: `password`）が設定されています。

## 使い方
1. **Windowsのモバイルホットスポットをオンにする**
   - 設定 > ネットワークとインターネット > モバイル ホットスポット をオンにします。
2. **アプリを起動する**
   - `send-files.exe` をダブルクリックして起動します。
   - コンソールに表示されるURL（例: `http://192.168.137.1:8080`）を確認します。
3. **iPad等から接続する**
   - WindowsのホットスポットにWi-Fi接続します。
   - ブラウザで上記URLにアクセスします。
   - 認証情報を入力します（`admin` / `password`）。
4. **ファイルの送受信**
   - 「Select Files」からファイルを選んで「Upload」で送信。
   - リストのファイル名をクリックしてダウンロード。

## ビルドとリリース
GitHub Actionsによって、タグ（`v*`）をプッシュすると自動的に `send-files.exe` がビルドされ、リリースに添付されます。
